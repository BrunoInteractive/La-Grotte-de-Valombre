TEST — CAHIER COLLAGE

1. Ouvrir la page 01 : une image de démonstration est déjà installée.
2. Cliquer sur « Cahier ».
3. Cliquer sur « Découper un indice dans l’image ».
4. Faire glisser le doigt ou la souris sur une zone de l’image.
5. Cliquer sur « Coller dans le cahier ».
6. Le morceau sélectionné apparaît comme un collage, avec le numéro de page.
7. Les collages sont sauvegardés avec la partie dans le stockage local du navigateur.

Cette version est uniquement un test du principe. L’histoire n’a pas été modifiée.
